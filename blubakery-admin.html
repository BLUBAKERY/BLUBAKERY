Productos, precios y stock
El stock se resetea manualmente cada semana. Poné 0 para marcar como agotado.
Box — producto especial
La Box aparece en la tienda como un producto más. El cliente la compra y después elige qué sabores le pone adentro. Vos ponés el precio final (ya con descuento aplicado) para que el cliente lo vea directo.
Si el cliente lleva Box + cookies sueltas extra, a las sueltas se les aplica este %. Poné 0 para no aplicar ningún descuento a las sueltas.

Box x 6 — producto especial
Igual que la Box de 4, pero con 6 cookies. El stock se descuenta del stock general de cada cookie elegida.

Cajas personalizables — armá la tuya
Cajas donde el cliente mezcla cookies premium y clásicas. No tienen precio fijo: el precio es la suma de las cookies elegidas menos el descuento (sin packaging), y el cliente lo ve recién cuando completa la caja. En la tienda aparecen en una sección aparte, debajo de las Box x 4 y x 6.
Para marcar una cookie como premium, o limitar cuántas entran por caja (ej. Nutella máx. 2), usá los campos de cada producto, arriba.
Cookie del mes
Elegí qué cookie se destaca este mes. Aparece arriba de todo en la tienda, en un banner especial. Se vende con el stock normal de esa cookie.
Boxes especiales / Lanzamientos
Cajas armadas con sabores fijos para fechas o ediciones especiales (Día del Padre, Mundial, etc.). Aparecen arriba en la tienda con banner destacado. Tienen su propio stock — no afectan al de las cookies sueltas.
Novedades (banner que rota)
Es el banner azul que muestra "lo que se viene", pasando una novedad por vez. Editá las que quieras, dejá vacías las que no uses.
Mostrar el banner de novedades en la tienda
El emoji es opcional (ej: 🍪 👔 ⚽ 🎁). Si una novedad no tiene título, no se muestra.
